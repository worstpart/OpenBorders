## 4. Things to know

| Fact | Detail |
|---|---|
| Nations and Airports | Rare by design: one Airport only while a teammate/human ally beyond their border is losing a war **and within reach**. Headless: 0.3–0.4 Airports and ~0.1 airlifts per team game; median lengths unchanged. Airlifts are mostly a human tool. |
| Regression tool | `node tools/hashDigest.mjs <root> <config> <seeds> [rulesJson]` — the new 4th argument passes rule overrides (e.g. `'{"flights":{"enabled":false}}'`) to the checkout under test. Worktree of the previous commit: `git worktree add <scratchpad>/wt-prev HEAD~1` |
| Headless | `--no-flights`; reports `airPerGame` and `rejectedReasons` (reasons, not only a count) |
| Browser: money for tests | Teammate bots can gift you gold: `ob.sendAs(mateId, {type:"donate", to: 1, resource:"gold", percentBp: 10000})` (gold gifts are legal anywhere) |
| Browser: coordinates | `ob.screenOf(tile)` returns CSS px; screenshots are scaled (e.g. ×0.78 at 1024 px wide) — scale before clicking |
| Browser: screenshots lag | A screenshot often shows the state before the last action: take a second one before concluding |
| Browser: early land grab | All land is taken within ~1 min at speed 4+; a human doing nothing is soon eliminated — expand or play at speed 1 |
| Shell | Heredocs with `'EOF'` are fine, but JS with apostrophes inside `node -e '…'` breaks: write patch scripts with the Write tool into the scratchpad and run `node file.cjs < /dev/null` |
| Dev server | This session used **`dev-5` (port 5177)**; `dev-4` belonged to another chat |
